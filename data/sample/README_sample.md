# Sample document

This is a placeholder. Delete this file and drop your own `.pdf`, `.md`,
or `.txt` documents into this `data/sample/` folder before running
`python scripts/ingest.py`.

Good first choices for a portfolio demo:
- Your university's course catalog or handbook (PDF)
- A popular open-source project's documentation (Markdown files)
- Public product manuals, FAQs, or a company's 10-K filing

Pick something a real person would actually want to search — that's what
makes the "real users" story work in interviews.
